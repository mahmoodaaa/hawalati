حوالتي — تشغيل بكبسة

نسخة عرض محلية. استخدم بيانات وملف اختبار فقط.

أول مرة

  1. ثبّت Docker Desktop من الموقع الرسمي وأكمل تجهيز WSL 2 إذا طلبه، ثم أعد تشغيل الجهاز عند الحاجة.
  2. افتح Docker Desktop وانتظر جاهزية المحرك. متطلبات الجهاز الحالية.
  3. فك ZIP كاملًا إلى مجلد داخل Documents. لا تشغّله من داخل الملف المضغوط.
  4. اضغط مرتين على START_HAWALATI.bat وانتظر ظهور «حوالتي جاهز».
  5. الموقع يفتح تلقائيًا: http://localhost:5173.

لا تحتاج IntelliJ أو VS Code أو Java أو Node أو تثبيت PostgreSQL منفصلًا.

التشغيل اليومي

  • تشغيل: START_HAWALATI.bat
  • إيقاف مع حفظ البيانات: STOP_HAWALATI.bat
  • فحص مشكلة: CHECK_SYSTEM.bat
  • رمز التحقق التجريبي: 123456
  • خطوات التجربة ومراجع الحوالات موجودة في DEMO_GUIDE.md.

إذا لم يفتح الموقع

افتح Docker Desktop وانتظر جاهزيته ثم أعد Start. إذا كان المنفذ 5173 مستخدمًا، أغلق نسخة التطوير السابقة. رسالة صور ناقصة تعني ضرورة استخراج مجلد images مع باقي الباكج. احتفظ بملف .env الذي يتولد محليًا ولا تشاركه. التفاصيل في START_HERE_AR.md وسجلات التشغيل في logs.

إعادة ضبط الديمو

RESET_DEMO.bat يحذف جميع حسابات وعمليات ووثائق ديمو حوالتي نهائيًا، بعد كتابة RESET HAWALATI. Enter يلغي الحذف. استخدم Stop للإيقاف المعتاد.

باكج Prebuilt يحتوي الصور الجاهزة؛ الإنترنت مطلوب لتنزيل وتجهيز Docker أول مرة. بيانات Docker لا تنتقل لجهاز آخر بنسخ المجلد. الحوالات التجريبية الحالية تنتهي في 2026-12-31.
