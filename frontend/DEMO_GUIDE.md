# حوالتي — دليل تجربة النظام

دليل العرض المعتمد أصبح في [DEMO_GUIDE.md بمجلد المشروع الرئيسي](../DEMO_GUIDE.md)، ليصل نفس الدليل إلى المطوّر وصاحب البزنس ضمن Hawalati-Demo.zip.

يشمل التسجيل الجديد، وثيقة الاختبار، OTP، بيانات المستفيد والحوالات المزروعة، الاستلام البنكي والمحافظ، السجل، البروفايل، تبديل اللغة، حفظ البيانات، والإيقاف وإعادة ضبط الديمو.

- صاحب البزنس: [START_HERE_AR.md](../START_HERE_AR.md) أو افتح START_HERE_AR.html؛ Docker Desktop ثم START_HAWALATI.bat.
- المطوّر: [README.md](README.md) لتشغيل React محليًا وفحوص الفرونت، و[دليل تجهيز الباكج](../delivery/README.md).

التطبيق يعتمد على Spring Boot وPostgreSQL في الحسابات والوثائق والعمليات. لا يمسح تنظيف المتصفح استلام الحوالة من قاعدة البيانات. الاستلام والتحقق المالي تجريبيان، ولا توجد تحويلات مالية أو SMS أو مطابقة وجه حقيقية.
